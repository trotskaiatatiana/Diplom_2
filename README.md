# Diplom_2 — Автоматизированное тестирование API Stellar Burgers

## Описание проекта

Дипломный проект по автоматизированному тестированию API веб-приложения Stellar Burgers.

Тесты написаны на Python с использованием Pytest и Requests. Для формирования отчётов используется Allure.

Тестируемое приложение: https://qa-stellarburgers.education-services.ru/

## Тестируемая функциональность

### Создание пользователя
- Успешное создание уникального пользователя.
- Проверка невозможности создания пользователя, который уже зарегистрирован.
- Проверка создания пользователя без одного из обязательных полей: `email`, `password`, `name`.

### Авторизация пользователя
- Успешная авторизация зарегистрированного пользователя.
- Авторизация с некорректным логином.
- Авторизация с некорректным паролем.

### Создание заказа
- Создание заказа с авторизацией.
- Создание заказа без авторизации.
- Создание заказа с ингредиентами.
- Создание заказа без ингредиентов.
- Создание заказа с некорректным хешем ингредиента.
